# Tutorial: conta no GitHub e como pedir ajuda

Usaremos o GitHub para três coisas: baixar os materiais, tirar dúvidas e receber o convite para o repositório privado do curso.

## 1. Criar a conta (5 minutos)

1. Acesse https://github.com/signup.
2. Informe e-mail, senha e um **nome de usuário**. Prefira algo que você não se importe em tornar público.
3. Confirme o e-mail que o GitHub enviar.
4. Envie o seu usuário no formulário (ou ao docente), para receber o convite do repositório.

## 2. Aceitar o convite

Quando você for sorteado(a), receberá um e-mail do GitHub com o convite para `acr-curso-2027`. Clique em **View invitation** e depois em **Accept invitation**. O convite expira em 7 dias.

## 3. Baixar os materiais (sem usar git)

1. Abra o repositório e clique no botão verde **Code**.
2. Clique em **Download ZIP** e descompacte a pasta.
3. Abra o arquivo `acr-curso-2027.Rproj` no RStudio.

A cada dia, baixe o ZIP de novo (ou apenas a pasta do dia), pois liberamos os slides e scripts de cada dia no dia anterior.

## 4. Tirar dúvidas

- **Discussions** (aba *Discussions*): dúvidas conceituais, de método e de organização. Procure antes se alguém já perguntou.
- **Issues** (aba *Issues*, botão *New issue*, modelo "Dúvida técnica"): erros de código, instalação e API.

### Como escrever uma boa dúvida técnica

1. Diga em qual script e em qual linha o erro aparece.
2. Cole a **mensagem de erro completa**, entre três crases (```) antes e depois.
3. Cole o resultado de `sessionInfo()`.
4. **Nunca cole sua chave de API.** Se colar sem querer, apague a mensagem e crie outra chave.

## 5. Regras de convivência

- Respeito ao falar com colegas e monitores.
- Não publique dados pessoais ou sensíveis de ninguém, nem seus.
- Os monitores respondem durante os horários do curso e, depois, em até um dia útil.
